# NUDO Engineering Paper design system

The book uses an industrial-document language around the official NUDO identity.
The editorial surface may be warm and aged; the NUDO mark itself remains the
official black/blue or single-colour delivered asset.

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| NUDO black | `#000000` | Official mark only / strong ink |
| NUDO blue | `#3F85FF` | Official accent and navigation focus |
| Paper light | `#F3EAD8` | Main reading surface |
| Paper warm | `#E7DCC7` | Cover and navigation |
| Paper aged | `#D8C6A8` | Secondary technical blocks |
| Ink | `#2B2926` | Body text |
| Graphite | `#55514C` | Secondary text |
| Rust | `#8A6142` | Industrial annotations, never the logo |
| Rule | `#B8AB93` | Grid/rules |

## Shape language

Square corners, hairline rules, technical metadata boxes and sparse construction
marks. No glow, no gradient-based AI motifs, no circuit boards, no fake wear that
reduces legibility.

## Logo rule

The theme references the official delivered NUDO assets. It does not create a
new lockup. On a standalone build where logo files are unavailable, the text name
`NUDO` is used as a safe fallback.
