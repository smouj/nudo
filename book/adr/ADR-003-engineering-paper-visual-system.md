# ADR-003 — Engineering Paper visual system

- **Status:** Accepted
- **Date:** 2026-09-17

## Decision

Use warm technical paper, graphite ink, thin rules, restrained rust annotations,
document IDs and revision boxes. Avoid green terminal nostalgia, fake circuitry,
neon glow and heavy grunge.

## Rationale

The book should feel like an engineered object, not an AI-product landing page.
