# ADR-002 — Only official delivered logo assets

- **Status:** Accepted
- **Date:** 2026-09-17

## Context

The NUDO brand document forbids redrawing, recolouring or reconstructing the logo.
Some horizontal variants are still pending.

## Decision

The book copies official delivered assets when available. It never synthesizes a
replacement. A standalone build falls back to the plain text name `NUDO`.

## Consequences

The Engineering Paper theme can use beige/rust editorial colours, but the mark
remains official black/blue or official monochrome.
