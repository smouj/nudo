# 05.2 — 任务、工具与模型

> **状态（Status）：** 提案中（PROPOSED）  
> **概述（Summary）：** NUDO 分离目标、有副作用的工具与模型供应商，使自主性可以被限定，而不把某一家厂商写进语言。


{{#include ../diagrams/interfaces.svg}}

*四种声明，以及约束它们各自的是什么。*

## 任务（Task）

任务是一单位自主工作，具有目标、预期结果、限制和可追溯性。
与普通的函数调用不同，任务应当产出关于工作如何被完成的证据。

## 工具（Tool）

工具把代码连接到外部能力：网络、文件系统、shell、Git 或其他服务。
因此工具调用是有副作用的，并受能力（capability）门控。

## 模型（Model）

模型是供应商中立的运行时接口。供应商 API 字段与认证不应改变
一个 NUDO 程序的含义。
