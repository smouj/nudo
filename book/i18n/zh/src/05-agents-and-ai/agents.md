# 05.1 — 作为有界执行器的智能体

> **状态（Status）：** 提案中（PROPOSED）  
> **概述（Summary）：** 智能体（agent）被设计为一个已声明的执行器，带有显式的工具、授权、限制与验收标准，而不是一个不受约束的提示词循环。

智能体声明（agent declaration）只有在传达编译器或运行时能够强制执行的信息时才有用。
因此，它的目的不是装饰性的组织。

审查者应当能够回答：

- 这个智能体可以调用哪些工具（tool）？
- 这些工具可以消耗哪些能力（capability）？
- 哪个模型（model）接口可用？
- 什么预算（budget）限制执行？
- 期望的输出类型是什么？
- 在继续之前需要什么验证（verification）或审批（approval）？

供应商特定的提示词与请求细节仍然属于运行时的职责。
