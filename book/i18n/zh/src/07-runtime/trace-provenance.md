# 07.1 — 追踪与来源

> **状态（Status）：** 提案中（PROPOSED）  
> **概述（Summary）：** 重要的自主执行应当留下足够的结构化证据，使人们无需逆向工程日志就能重建发生了什么。

追踪（trace）是一段执行叙事。来源（provenance）是附着在值上的数据血缘（lineage）。
两者有重叠，但并不相同。

对已验证的值而言，一条有用的来源记录可能需要指明来源模型/工具、相关输入、
验证步骤、策略决定和审批。确切的模式（schema）仍是一项实现/规范任务；
不变量是：信任不应与产生它的证据分离。

在结构上，追踪应尽可能具有确定性，即使事件内部的模型内容是概率性的。
