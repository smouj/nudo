# 02.2 — 表达式与优先级

> **状态（Status）：** 待定（Open）  
> **概述（Summary）：** 在 M2 被认为对下游工具足够稳定之前，表达式优先级（precedence）与结合性（associativity）必须无歧义。

优先级不是格式细节。`a + b * c` 在每一个符合规范（conforming）的实现中只能有一种含义。

解析器设计应当使这些性质显式化：

- 后缀运算比一元运算符结合得更紧；
- 乘除比加减结合得更紧；
- 比较与相等具有已定义的可链式行为；
- 布尔运算符具有固定的优先级；
- 赋值如果被引入，必须定义结合性；
- 未来的 `ask`、`verify` 或 `delegate` 形式必须说明它们是基本表达式、前缀表达式还是声明。

格式化器应当输出足够的语法以保住含义，而不依赖人的直觉。
