# 00.1 — 什么是 NUDO？

> **状态（Status）：** 规范已定义（SPECIFIED）  
> **概述（Summary）：** NUDO 被设计为一种通用语言：在其中，确定性（deterministic）代码与有界的概率性（probabilistic）工作可以共存，而不隐藏信任（trust）或授权（authority）边界。

## 一句话模型

NUDO 在一套类型、权限（permission）和验证（verification）体系之下，
连接人、代码、智能体（agent）、工具（tool）和模型（model）。

## 这个项目的不同之处

大多数应用语言只能把模型调用表示为普通的库 I/O。这意味着编译器看到的是一个函数调用，
也许还有一个 JSON 值，但它并不知道这个值是概率性生成的、调用方授予了何种授权、
消耗了多少预算（budget），或者是否有人验证过结果。

NUDO 探索的是把这些边界移入语言可见的结构，同时让普通的确定性编程保持为默认路径。

## 它不是什么

NUDO 不是模型 SDK、不是提示词（prompt）框架、不是厂商专用 DSL，也不是 Python 的新外壳。
供应商特定的请求形态属于运行时适配器（adapter）。提示词组合主要属于库。
语言负责的是独立实现必须达成一致的语义、信任与授权规则。
