# 06.1 — 能力、效果与授权

> **状态（Status）：** 提案中 / 计划中（PROPOSED / PLANNED）
>
> **概述（Summary）：** NUDO 提议进行静态效果跟踪并显式表示能力授权；当前工具链既没有效果检查，也没有运行时能力执行机制。

{{#include ../diagrams/authority.svg}}

*这是提议中的授权模型，不是今天由运行时执行的安全边界。*

## 三个相关概念

- **效果（Effect）**：对某个计算可能执行何种操作的静态描述，例如使用网络。
- **能力授予（Capability grant）**：向程序或执行上下文提供的授权。
- **策略（Policy）**：限制授权何时或以何种方式可以行使的规则。

该设计会把函数所需的效果与调用点可用的授权关联起来。它的目标是默认拒绝，
并防止被委托的工具或智能体扩大调用方授予的权限。
