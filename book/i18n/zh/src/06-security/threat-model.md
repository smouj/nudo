# 06.2 — 威胁模型

> **状态（Status）：** 规范已定义 / 计划中（SPECIFIED / PLANNED）  
> **概述（Summary）：** 在显式规则把数据跨越信任边界之前，NUDO 把模型输出和外部工具输入视为不可信。

威胁模型包括提示注入（prompt injection）、恶意的工具输出、能力提升（capability escalation）、
密钥外泄（secret exfiltration）、无界执行、来源丢失和运行时适配器（adapter）缺陷。

仅靠语言检查无法保障一个操作系统的安全。静态效果规则必须与运行时强制执行和沙箱化（sandboxing）
配合，在副作用跨越进程或宿主边界之处发挥作用。

一个成熟的实现应当同时测试正向与负向保证：不仅是被允许的程序可以工作，
而且被拒绝的效果在效果发生*之前*就失败。
