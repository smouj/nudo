# 11.1 — 为什么选择 Rust，为什么自建编译器？

> **状态（Status）：** 规范已定义的论证（SPECIFIED rationale）  
> **概述（Summary）：** Rust 提供了强大的实现基座，而如果 NUDO 语义要独立于另一种宿主语言存在，专用编译器就是必需的。

## 为什么用 Rust 实现

Rust 提供显式的所有权、强静态检查、良好的性能、成熟的解析器/编译器工具链
以及实用的跨平台分发。这并不使 Rust 成为 NUDO 语言语义的一部分；它是实现语言。

## 为什么不编译到 Python 并以其为定义？

如果 NUDO 语义只是 Python 语义加语法，Python 就会成为真正的规范。
信任类型、能力检查和稳定的编译器诊断等特性会继承宿主语言的约束。

专用编译器让 NUDO 规范保持权威。后端以后可以更换，而不必重新定义程序的含义。
