# 04.1 — 类型系统基础

> **状态（Status）：** 提案中（PROPOSED）  
> **概述（Summary）：** 类型系统偏好显式的公开签名、名义（nominal）关系，以及编译器可见的信任/效果信息。

当前的设计约束包括标量基本类型、结构体（struct）、枚举（enum）、序列、
函数、泛型（generic）以及可选/类结果（optional/result-like）形式。

公开接口应当被标注。局部推断可以减少噪声，但公开 API 的类型不应暗中依赖实现细节。

诸如整数位宽、溢出语义、型变（variance），以及运行时提供的能力（capability）的确切表示
等开放问题，必须有意识地解决。
