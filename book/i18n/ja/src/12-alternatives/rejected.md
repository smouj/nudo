# 12.1 — 意図的に却下された代替案

> **ステータス:** 歴史的 (Historical) / 設計の根拠 (Design rationale)  
> **概要:** より単純ないくつかのアプローチはアプリケーションでは有用ですが、言語から可視なトラストと権威という NUDO の目標を満たしません。

| 代替案 | 言語モデルとして不十分な理由 |
| --- | --- |
| 通常の文字列としてのプロンプト | コンパイラは散文からトラストや権威を推論できない。 |
| デプロイ設定にのみ置かれた権限 | ソースレベルの呼び出しを付与の経路に対して検査できない。 |
| `verified: Bool` フラグ | 安全性が任意のランタイム慣習になる。 |
| プロバイダー固有のキーワード | 言語の意味をベンダーの API に結合する。 |
| 無制限のエージェントループ | 権威、予算、停止性をレビューしにくくする。 |
| ログのみの来歴 | 事後にエビデンスを再構成し、値の系譜を失い得る。 |

これらの技法は、ランタイムアダプターやライブラリの中で今も現れ得ます。ここでの却下は「言語の意味論的な基盤ではない」という意味であり、「決して役に立たない」という意味ではありません。
