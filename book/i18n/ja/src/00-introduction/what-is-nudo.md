# 00.1 — NUDO とは何か

> **ステータス:** 仕様化済み (Specified)  
> **概要:** NUDO は汎用言語として設計されており、その中で決定論的なコードと境界付けられた確率的な処理が、トラストや権威の境界を隠すことなく共存できます。

## 一文で表すモデル

NUDO は、人、コード、エージェント、ツール、モデルを、単一の型・権限・検証の体系の下に接続します。

## このプロジェクトを特異にしているもの

ほとんどのアプリケーション言語は、モデル呼び出しを通常のライブラリ I/O としてしか表現できません。つまりコンパイラが見るのは関数呼び出しと、おそらく JSON 値だけであり、その値が確率的に生成されたものであること、呼び出し側がどのような権威を付与したか、どの予算が消費されたか、誰かがその結果を検証したかどうかは分かりません。

NUDO は、通常の決定論的プログラミングを既定の道筋として保ちながら、それらの境界を言語から可視な構造へと移すことを探求します。

## そうではないもの

NUDO はモデル SDK でも、プロンプトフレームワークでも、ベンダー固有の DSL でも、Python に新しい皮をかぶせたものでもありません。プロバイダー固有のリクエスト形状はランタイムアダプターに属します。プロンプトの構成は、ほとんどがライブラリに属します。言語が担うのは、独立した実装同士が一致しなければならない意味、トラスト、権威の規則です。
