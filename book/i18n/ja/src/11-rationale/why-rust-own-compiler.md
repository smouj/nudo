# 11.1 — なぜ Rust なのか、なぜ独自のコンパイラなのか

> **ステータス:** 仕様化済みの根拠 (Specified rationale)  
> **概要:** Rust は強力な実装基盤を提供し、NUDO の意味が別のホスト言語から独立して存在することを意図するのであれば、専用のコンパイラが必要です。

## 実装に Rust を使う理由

Rust は、明示的な所有権、強力な静的検査、良好な性能、よく整備されたパーサー・コンパイラ向けツール、実用的なクロスプラットフォーム配布を提供します。しかしそのことは Rust を NUDO の言語の意味の一部にするものではありません。Rust は実装言語です。

## なぜ定義として Python へコンパイルしないのか

NUDO の意味が単に Python の意味に構文を足したものなら、Python が実質的な仕様になります。トラスト型、ケイパビリティ検査、安定したコンパイラ診断といった機能は、ホスト言語の制約を引き継ぐことになります。

専用のコンパイラがあれば、NUDO の仕様が権威であり続けられます。バックエンドは、プログラムの意味を再定義することなく、後から変更できます。
