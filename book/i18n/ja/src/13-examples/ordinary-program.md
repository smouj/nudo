# 13.1 — 通常の決定論的プログラム

> **ステータス:** 提案中の構文 (Proposed syntax)  
> **概要:** 小さな決定論的プログラムが、通常のコードが単純であり続けるという設計要件を示します。

```nudo
fn add(a: Int, b: Int) -> Int {
    a + b
}

fn main() {
    let total = add(20, 22);
    print(total);
}
```

この例は、現在実装されている字句解析器を超えた、意図された方向性を表します。標準ライブラリの `print` API の正確な形と、パーサーによる受理は、後のマイルストーンに依存します。
