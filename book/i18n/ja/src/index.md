NUDO は汎用プログラミング言語のプロジェクトです。通常の決定論的プログラムに、制限付きの確率的処理を含めつつ、データの信頼性、必要な権限、検証をプログラム内で可視化する設計を目指します。プロジェクトは pre-alpha です。動作するフロントエンドと部分的な型検査 crate はありますが、NUDO プログラムを実行することはできません。

本書は動機、採用済みの言語規則、コンパイラー設計、実装済みの動作、未解決の提案、計画中の runtime を説明します。規範仕様より広い範囲を扱うため、例はそれぞれの status と合わせて読んでください。言語を定義するのは仕様であり、本書が規則を追加することはありません。

## 本書の読み方

設計を知るには「哲学」と「信頼」から始めてください。実装済みのコンパイラーについては「言語設計」→「コンパイラー」→「型システム」を読んでください。今後のエージェント runtime については「エージェントと AI」→「セキュリティ」→「Runtime」を読んでください。マイルストーン表は、動作するコード、採用済み規則、提案を区別します。

## 現在動作するもの

- <code>nudo check</code> は <code>.nudo</code> ファイルを読み込み、字句解析と構文解析を行い、名前を解決して、字句・構文・名前解決の診断を報告します。
- <code>--dump-tokens</code>、<code>--dump-tree</code>、<code>--dump-resolutions</code> は各段階を安定した形式で表示します。
- Rust crate には部分的な型チェッカーがあります。実装済み規則は unit test と型検査の適合性コーパスで検証されますが、<code>nudo check</code> にはまだ接続されていません。
- ベンチマーク suite は lexer、parser、HIR lowering、型検査の合成 workload を測定します。NUDO プログラムの実行時間は測定しません。

<code>nudo run</code>、<code>nudo build</code>、インタープリター、エフェクトチェッカー、エージェント runtime、ツール呼び出し、policy 強制、provenance recorder、WebAssembly backend はまだありません。

## 正式な権威

言語は仕様が定義します。採用済み NEP が仕様を改訂します。適合性テストは観測可能な動作を固定します。本書は規則を説明し、今後の作業にラベルを付けます。提案を実装済みの機能に格上げすることはありません。
