# 06.1 — ケイパビリティ、エフェクト、権威

> **ステータス:** 提案中 (Proposed)  
> **概要:** エフェクトは実行が何を行い得るかを記述し、ケイパビリティは現在のコンテキストが実際に付与できる権威を記述します。


{{#include ../diagrams/authority.svg}}

*権威は委譲の連鎖に沿って狭まり、逆流することはありません。*

これらの概念は、混同されることなく関連付けられなければなりません。

- **エフェクト**: 計算がネットワークアクセスのような操作を行い得るという静的な記述。
- **ケイパビリティ付与**: コンテキストに対して利用可能にされた権威。
- **ポリシー**: その権威をいつ、どのように行使できるかを制限する規則。

既定は拒否であることが意図されています。ホストプロセスがたまたま持っているというだけで、コードがネットワーク、ファイルシステム、シェル、シークレットへのアクセスを得るべきではありません。

重要な不変条件は非増幅 (non-amplification) です。ツールや委譲されたエージェントは、呼び出し側が付与したものを超えて自らの権威を広げられてはなりません。
