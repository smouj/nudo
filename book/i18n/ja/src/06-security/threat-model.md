# 06.2 — 脅威モデル

> **ステータス:** 仕様化済み (Specified) / 計画中 (Planned)  
> **概要:** NUDO は、明示的な規則がデータをトラスト境界の向こう側へ移すまで、モデル出力と外部ツールの入力を信頼しないものとして扱います。

脅威モデルには、プロンプトインジェクション、悪意あるツール出力、ケイパビリティの昇格、シークレットの漏えい、無制限の実行、来歴の喪失、ランタイムアダプターの不具合が含まれます。

言語の検査だけではオペレーティングシステムを保護できません。静的なエフェクト規則は、副作用がプロセスやホストの境界を越える場所でのランタイムの強制とサンドボックス化と組み合わせなければなりません。

成熟した実装は、肯定的な保証と否定的な保証の両方をテストすべきです。許可されたプログラムが動作することだけでなく、拒否されたエフェクトがそのエフェクトの発生*前に*失敗することも確かめるべきです。
