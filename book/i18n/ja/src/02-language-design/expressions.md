# 02.2 — 式と優先順位

> **ステータス:** 未決 (Open)  
> **概要:** 式の優先順位と結合性は、M2 が下流のツールにとって十分安定したと見なされる前に、曖昧さなく定まっていなければなりません。

優先順位は整形上の些事ではありません。`a + b * c` は、すべての適合実装において一つの意味を持たなければなりません。

パーサーの設計は、次の性質を明示すべきです。

- 後置演算は単項演算子よりも強く結合する;
- 乗算・除算は加算・減算よりも強く結合する;
- 比較と等価性は、定義された連鎖 (chaining) の挙動を持つ;
- ブール演算子は固定の優先順位を持つ;
- 代入は、導入される場合、結合性を定義しなければならない;
- 将来の `ask`、`verify`、`delegate` 形式は、それらが一次式、前置式、宣言のいずれであるかを述べなければならない。

フォーマッタは、人間の直感に依存せずに意味を保つだけの構文を出力すべきです。
