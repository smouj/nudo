# 02.3 — モジュールとプログラムの境界

> **ステータス:** 提案中 (Proposed)  
> **概要:** モジュールは、権威や依存関係の境界を隠すことなく、明示的な名前空間と再現可能なプログラム構造を提供しなければなりません。

モジュールの設計は、パッケージの設計、名前解決、公開インターフェースと密接に関係します。NUDO は暗黙のグローバル名前空間を避け、公開 API の表面を意図的に設計されたものにすべきです。

未解決の設計作業には、パッケージマニフェスト、可視性、依存関係の解決、そして依存関係が宣言するケイパビリティを呼び出し側にどう提示するかが含まれます。
