# 08.1 — ツールチェーンと CLI

> **ステータス:** 実装済み (Implemented) / 計画中 (Planned)  
> **概要:** `nudo` コマンドは、今日の字句検査から、将来のビルド、実行、フォーマット、テスト、監査、トレースのワークフローまで、一貫した単一の入口を提供するべきです。

現在実装されているコマンドには、字句検査と基本的な CLI メタデータが含まれます。将来のロードマップ上のコマンドには、ビルド、実行、REPL、フォーマッタ、ドキュメント、テスト、評価、doctor/audit、トレースが含まれます。

コマンドの表面は予測可能であり続けるべきです。安定した終了コード、必要に応じた機械可読な出力、診断コード、そして暗黙のネットワーク活動がないことです。
