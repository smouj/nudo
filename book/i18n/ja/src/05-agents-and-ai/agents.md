# 05.1 — 境界付けられた実行者としてのエージェント

> **ステータス:** 提案中 (Proposed)  
> **概要:** エージェントは、明示的なツール、権威、制限、受け入れ基準を持つ宣言された実行者であることが意図されており、制約のないプロンプトループではありません。

エージェントの宣言は、コンパイラやランタイムが強制できる何かを伝える場合にのみ有用です。したがってその目的は、見た目を整えるための整理ではありません。

レビュー担当者は次のことに答えられるべきです。

- このエージェントはどのツールを呼び出せるか。
- それらのツールはどのケイパビリティを消費できるか。
- どのモデルインターフェースが利用可能か。
- どの予算が実行を制限するか。
- どのような出力型が期待されるか。
- 続行の前にどのような検証や承認が必要か。

プロバイダー固有のプロンプトとリクエストの詳細は、ランタイムの関心事のままです。
