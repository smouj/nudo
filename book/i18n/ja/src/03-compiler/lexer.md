# 03.2 — ソースモデルと字句解析器

> **ステータス:** 実装済み (Implemented)  
> **概要:** 字句解析器は最初の実質的な言語実装層であり、決定論的なトークン化と回復可能な字句診断を担います。

堅牢な字句解析器は、バイト位置、行・列の対応、ソース ID を保持し、後の診断が元のソースを正確に参照できるようにしなければなりません。

重要な性質には次のものが含まれます。

- UTF-8 のソース読み込み;
- 決定論的なトークン列;
- 字句仕様に従った入れ子コメント・ブロックコメントの規則;
- 最初のエラーでパニックするのではなく、不正な入力から回復する;
- 安定した診断コード;
- 別の実装が再現できる適合性テストケース。

現在の `nudo check` の成功経路は字句レベルのみです。クリーンな結果は、まだプログラムが構文的あるいは意味的に妥当であることを意味しません。
