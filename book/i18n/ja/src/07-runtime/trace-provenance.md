# 07.1 — トレースと来歴

> **ステータス:** 提案中 (Proposed)  
> **概要:** 重要な自律的実行は、ログを逆解析することなく何が起きたかを再構成できるだけの構造化されたエビデンスを残すべきです。

トレースは実行の語りです。来歴 (provenance) は値に付随するデータの系譜です。両者は重なりますが、同一ではありません。

検証された値にとって有用な来歴の記録は、ソースとなったモデルやツール、関連する入力、検証の段階、ポリシーの決定、承認を特定できる必要があるかもしれません。正確なスキーマは実装および仕様の課題として残りますが、不変条件は、トラストがそれを生み出したエビデンスから切り離されてはならないということです。

トレースは、可能な限り構造が決定論的であるべきです。たとえイベント内部のモデル内容が確率的であっても。
