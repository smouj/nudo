# 07.2 — 予算と承認

> **ステータス:** 提案中 (Proposed)  
> **概要:** 予算はリソース消費を制限し、承認は自律的なワークフローに明示的な人間またはポリシー制御のゲートを作ります。

予算は金額以上のものを表せます。有用な次元には、呼び出し回数、経過時間、トークン数、リトライ回数、プロバイダーコストが含まれます。ランタイムは、どの制限が権威的であるか、また複数の制限に同時に到達したときに何が起きるかを定義しなければなりません。

承認は非公式なチャットメッセージではなく、第一級のイベントであるべきです。承認の記録は、誰が、あるいは何が承認したか、正確にどの値や操作が承認されたか、どのポリシーの下で承認されたかを述べるべきです。
