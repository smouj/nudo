# 09.1 — MCP、A2A、WebAssembly

> **ステータス:** 計画中 (Planned)  
> **概要:** 相互運用性は、アダプターが権威を広げることを許すことなく、NUDO が既存のツールとエージェントのエコシステムに参加できるようにするべきです。

MCP の相互運用性により、NUDO はツールを消費または公開できます。A2A 形式の委譲は、独立したエージェント実装同士を接続できます。WASI は、明示的なホストケイパビリティを備えたポータブルな実行ターゲットを提供できます。

セキュリティ上の規則は、プロトコルの互換性よりも強いものです。アダプターは、NUDO の呼び出し側が持っていなかったケイパビリティを自らに付与することを信頼されてはなりません。
