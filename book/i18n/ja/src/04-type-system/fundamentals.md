# 04.1 — 型システムの基礎

> **ステータス:** 提案中 (Proposed)  
> **概要:** 型システムは、明示的な公開シグネチャ、名前的 (nominal) な関係、コンパイラから可視なトラスト・エフェクト情報を優先します。

現在の設計上の制約には、プリミティブなスカラー型、構造体、列挙型、シーケンス、関数、ジェネリクス、およびオプション・結果に類する形式が含まれます。

公開インターフェースには注釈を付けるべきです。ローカルな型推論はノイズを減らせますが、公開 API の型が実装の詳細に暗黙に依存してはなりません。

整数幅、オーバーフローの意味論、変性 (variance)、ランタイムが提供するケイパビリティの正確な表現といった未解決の問いは、意図的に解決されなければなりません。
