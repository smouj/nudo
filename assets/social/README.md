# `assets/social/` — social and preview images

**Empty and pending.** Social cards, repository preview images and profile
banners are not produced yet.

This directory holds a README instead of placeholder images, because a
placeholder that is checked in is a placeholder that gets shipped.

## Why nothing is here yet

The horizontal logo lockups do not exist yet — see
[`../brand/BRAND.md`](../brand/BRAND.md#pending-assets). A repository preview
image is built from the lockup, so producing one now would mean inventing the
missing assets, which the brand rules forbid.

## What will go here

| Asset | Size | Use |
| ----- | ---- | --- |
| Repository preview | 1280×640 | GitHub social preview |
| Profile banner | 1500×500 | Organisation or maintainer profile |
| Announcement card | 1200×630 | Web and social sharing |

## Rules for whoever produces them

* Use the delivered lockup, unmodified. Do not reassemble it from the symbol and
  the wordmark.
* One accent colour per image.
* No photographic texture, no glow, no gradient background.
* The image must still read at 320 px wide, which is what a phone shows in a
  timeline.
* Text is limited to the name and, at most, one line describing the project as a
  programming language. "Pre-alpha" is stated only where the surrounding context
  does not already say it.
